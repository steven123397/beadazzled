The first patch release. It fixes adding a workspace when beadazzled is launched from
its install folder — the normal Start-menu path — and makes bd failures readable.

**Requirements:** Windows 10/11 x64 (WebView2) · `bd` 1.3.2 or newer on `PATH`, or
configured in Settings → bd.

## Fixed

- **Adding a workspace failed with “bd rejected the change.”** bd 1.3.2 resolves the
  git repository from the process working directory even when `-C` names the workspace.
  Launched from the install folder (the shortcut's default working directory), every add
  failed with “not a git repository”. beadazzled now runs bd inside the selected
  workspace, so adding works from any launch location.
- **bd errors written to stdout were hidden.** `bd context --json` reports an unusable
  workspace as JSON on stdout with an empty stderr; the app only read stderr and showed a
  generic rejection. It now reads both and shows bd's own message.

## Updating

v0.1.0 installs can update from **Settings → About → Check for updates** (signed
minisign update, passive install). Or download `beadazzled_0.1.1_x64-setup.exe` below.

This build is not Authenticode-signed; Windows SmartScreen may warn about an unknown
publisher. Confirm the checksum below before running.

## 中文

第一个补丁版本。修复从安装目录启动（即开始菜单的默认方式）时无法添加工作区的问题，
并让 bd 的失败原因可见。

**修复：**

- **添加工作区提示 “bd rejected the change.”** bd 1.3.2 即使在 `-C` 指定工作区时，
  仍然用进程当前目录判断 git 仓库；从安装目录启动时必然失败。现在 beadazzled 会在
  所选工作区内运行 bd，任何启动位置都能添加。
- **写在 stdout 上的 bd 错误被吞掉。** `bd context --json` 对不可用工作区会把错误写成
  stdout 上的 JSON、stderr 为空；应用只读 stderr，只能显示一句笼统的拒绝。现在两路
  都读，并显示 bd 的原文。

**更新方式：** v0.1.0 可在 Settings → About → 检查更新 中升级；或直接下载下方安装包。

本构建未做 Authenticode 签名，SmartScreen 可能提示未知发布者；运行前请核对下方校验和。
