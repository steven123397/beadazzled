## 修复内容

1. **从安装目录启动时添加工作区失败**：bd 1.3.2 即使带 `-C` 也用进程 cwd 判断 git 仓库；
   bridge 现在把子进程 cwd 设为工作区。
2. **bd 写在 stdout 的 JSON 错误不可见**：错误分类同时读 stdout，界面显示 bd 原文。
3. **journal 回放清空评论与依赖**：事件负载不含 comments/dependencies，原先整体替换 issue；
   现在改为合并，并追加评论、维护依赖列表与计数。
