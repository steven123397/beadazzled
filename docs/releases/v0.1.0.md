A Windows desktop client for [beads](https://github.com/gastownhall/beads) (`bd`) —
List, Board, Detail and Settings, keyboard-first, with signed in-app updates.

**Requirements:** Windows 10/11 x64 (WebView2) · `bd` 1.3.2 or newer on `PATH`, or
configured in Settings → bd. beadazzled never bundles `bd`.

## Install

1. Download `beadazzled_0.1.0_x64-setup.exe` below.
2. Check its SHA-256 against the value in **Checksums** before running it.
3. Run it. It installs per-user to `%LOCALAPPDATA%\beadazzled` and needs no
   administrator rights. Add a workspace on first launch.

Uninstall from Settings → Apps, or with `uninstall.exe` in the install folder.

### Windows SmartScreen

This build is **not Authenticode-signed**. Windows may show “Unknown publisher” or
“Windows protected your PC” the first time you run it. That is expected — this project
does not claim OS-level publisher trust. Confirm the download came from this release,
check the SHA-256, then choose **More info → Run anyway**.

Update packages are signed separately with minisign and are rejected if the signature
does not match the key built into the app.

## What's new

- List, Board, Detail and Settings share one design language, in light and dark.
- Virtualised list and board for 1000+ tickets: filters, grouping, saved views and
  URL-addressable state; keyboard move on the board.
- Markdown detail view with metadata, dependency and comment editing. Status changes
  are written back through `bd`.
- Keyboard-first throughout, with a command palette and deep links.
- Signed NSIS installer, and automatic updates served from this repository.

## Known limitations

- No dependency graph or dependency editing yet.
- Windows only; macOS and Linux are not supported.
- The interactive installer wizard and in-place upgrades have not been exercised yet;
  silent install and uninstall are tested.
- The app is not code-signed, so the SmartScreen prompt described above is normal.

## 中文

面向 [beads](https://github.com/gastownhall/beads)（`bd`）的 Windows 桌面客户端：
List、Board、Detail、Settings 四个视图，键盘优先，支持签名的自动更新。

**环境要求：** Windows 10/11 x64（WebView2）；`bd` 1.3.2 或更新，在 `PATH` 中或在
Settings → bd 里指定。beadazzled 不捆绑 `bd`。

**安装：** 下载 `beadazzled_0.1.0_x64-setup.exe`，先核对下方 SHA-256，再运行。
按当前用户装到 `%LOCALAPPDATA%\beadazzled`，不需要管理员权限；首次启动后添加工作区。
卸载走「设置 → 应用」，或安装目录里的 `uninstall.exe`。

**SmartScreen：** 本构建未做 Authenticode 代码签名，首次运行可能提示「未知发布者」。
这是预期行为；请确认安装包来自本发布页且 SHA-256 一致，再选择「更多信息 → 仍要运行」。
更新包另外用 minisign 签名，签名不符会被拒绝。

**本版内容：** 统一设计语言的四个视图（明/暗）；1000+ 条的虚拟化列表与看板、筛选、
分组、保存视图与 URL 状态；Markdown 详情阅读与元数据、依赖、评论编辑，状态经 `bd`
写回；全程键盘可达、命令面板与深链接；签名 NSIS 安装包与自动更新。

**已知限制：** 暂无依赖图与依赖编辑；仅支持 Windows；交互式安装向导与原地升级尚未
走查（静默安装与卸载已测试）；未做代码签名，SmartScreen 提示属正常现象。
