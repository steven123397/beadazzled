# beadazzled v0.1.0

状态：发布候选（2026-11-04）。本地产物已验证；尚未上传 GitHub Release。
平台：Windows x64。许可证：MIT（[LICENSE](../../LICENSE)）。

## 这个版本是什么

面向 bd 的 Windows 桌面前端：List / Board / Detail / Settings 四个视图、键盘优先、
文档级阅读、经 bd 持久化的常规写操作、自动更新。

主要变更：

- 统一设计语言：List、Board、Detail、Settings 共用 tokens 与 primitives；
  浅/深两套主题、42px 行高、统一 120ms 动效、reduced-motion 折叠。
- Settings 改为左栏目 + 分栏目路由（ADR-0010），About 重做，新增应用图标。
- 列表/看板虚拟化、分组、筛选与 URL + 保存视图；看板派生列与键盘移动。
- 详情页 Markdown 阅读、元数据编辑、依赖与评论。
- 自动更新：Tauri updater（minisign）、启动后一次检查 + About 手动检查、
  passive 安装、GitHub `latest` 端点。
- 发布工程：NSIS currentUser 安装包、NOTICE/LICENSE 随包、版本三处一致、
  `check:size`、`verify:release`、`make:latest`、真实桌面 E2E。

## 安装与卸载

- 资产：`beadazzled_0.1.0_x64-setup.exe`（2.15 MB）+ `.sig` + `latest.json`。
- 安装：双击 NSIS 安装包，按当前用户安装到 `%LOCALAPPDATA%\beadazzled`，
  不需要管理员权限。
- 卸载：设置 → 应用，或安装目录的 `uninstall.exe`；卸载同时删除
  `LICENSE` 与 `NOTICE`。
- **未做 Authenticode 代码签名**：Windows SmartScreen 可能提示「未知发布者」。
  本项目不宣称已获得系统信任；请核对下载页与 SHA-256 后再运行。

## 自动更新

- 端点：`https://github.com/steven123397/beadazzled/releases/latest/download/latest.json`。
- 启动后 10s 检查一次；About 提供手动检查；失败在 About 显示原因，不打扰启动。
- 更新包必须通过内置公钥验签；版本不更高或签名不匹配时拒绝。
- 签名私钥不在仓库内；口令用 DPAPI 保护。首次发布前必须离线备份，
  丢失会导致已安装用户无法自动更新。
- **更新闭环未完整演示**：需要先发布 v0.1.0，再发布 v0.1.1 才能走
  「下载 → 验签 → passive 安装 → 重启」；本地已验证 `.sig` / `latest.json`
  一致性及篡改拒绝（`verify:release`）。

- 无 Authenticode 签名（见上）。

- 交互式安装与原地升级未验证。
- 64 KiB 首渲染 P50 在 92–103ms 间波动，单轮可能略高于 100ms 预算。
- 热启动 P95 有一轮 807ms；未优化、未改预算，若固定环境连续三次超标再处理。
- 自动更新依赖 GitHub `releases/latest`；没有正式 Release 时检查会报错。
